# Authority citation reconciliation

One entry per distinct section cited by `src/`. Statuses are those defined in the
Phase 22 instruction.

| Status | Meaning here |
|---|---|
| `VERIFIED_HISTORICAL` | Recovered verbatim text exists, inside a document that is preserved for provenance and does not govern current implementation. |
| `MISSING_AUTHORITY` | No text anywhere accessible. The citation records where a rule came from; it cannot demonstrate the rule. |
| `VERIFIED_CURRENT` | Would require a governing document present in this repository. **No Bible citation qualifies.** |
| `MIS-CITED` / `RETIRED` / `REPOINTED` | **None.** No mis-citation was found, and nothing was repointed — see `AUTHORITY_DECISIONS.md`. |

historical: their text survives inside AEON X's constitutional corpus, which governs

and it does not make it this product's law.
